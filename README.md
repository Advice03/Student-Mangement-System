# StudentMS — Student Management System

A responsive HTML, CSS and JavaScript learning project for a student management website.

## Features
- Public home page with About and Features sections
- Register and login
- Protected dashboard, students, profile and record pages
- Add, search, filter, view, edit and delete student records
- Profile page
- Responsive navigation and consistent campus background

## Run in VS Code
1. Extract this folder.
2. Open the `StudentMS_Full_Project` folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.
5. Register a new account, then log in.

## Important
This is a front-end learning demo. User accounts and student records are stored in the browser's LocalStorage. Passwords are not securely hashed and there is no server-side authorization. Do not use real or sensitive student information. A production system requires a backend, secure password hashing, server-side sessions/authorization, and a database.
